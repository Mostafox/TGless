# tgless

TypeScript framework for Telegram Serverless (tgcloud) bots: modules + DI, a typed ORM, npm bundling and a test harness.

```bash
npm create tgless@latest my-bot
```

- Full guide / API reference: [AGENTS.md](./AGENTS.md) (also copied into every new project)
- Repository & examples: https://github.com/Mostafox/TGless
