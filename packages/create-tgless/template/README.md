# __NAME__

A Telegram bot built with [tgless](https://github.com/Mostafox/TGless) for Telegram Serverless (tgcloud).

```bash
npm install
npx tgcloud login     # link this folder to your bot (once)
npm run dev           # rebuild on every change
npm run deploy        # build + push to tgcloud
npm run migrate       # apply database schema changes
npm test              # run the tests locally (in-memory DB, no network)
```

Code lives in `src/`. `tgcloud/` is generated by `tgless build`; don't edit it.
See [AGENTS.md](AGENTS.md) for the full guide.
